# Boss portraits

Drop boss images in this folder, named after the boss flag id: `<flag_id>.png`.
`.jpg` is used as a fallback when no `.png` exists. Any image the overlay cannot find is
simply skipped, so a partial set works fine.

Flag ids are language independent, so one set of images covers every language.

The list layout scales images to `random_image_size` pixels tall and the grid layout scales
them to the column width, both preserving aspect ratio. Roughly square images around 256x256
work well for both.

Only base game bosses can be drawn in a Random Run, so only these 165 files are ever used.
