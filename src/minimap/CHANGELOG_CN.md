# 更新日志

本项目所有重要变更均记录于此文件。

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)。

---

### [Unreleased]

#### 配置格式变更

- 将平铺键名和多行逗号列表改为分区与独立命名预设；保留全部现有快捷键、标记开关和显示调整能力。
- 位置与缩放分别填写，边框直接使用像素宽度；重写 INI 注释和配置说明。无效值使用字段默认值，不抛出异常。
- 位置支持居中或四向边距组合，按小地图对应角落定位；边距支持像素、屏幕百分比和负值，尺寸变化及圆形模式保持所选锚点。
- 请用新模板替换旧 minimap.ini；旧配置键不再读取。

#### 新增

- 新增内部卢恩死亡标记，`[markers] death = true` 默认开启。跟随游戏死亡记录更新，回收卢恩后或处于其他地图层时隐藏。
- 新增玩家放置的编号地图标记 1～5，使用内部下箭头和动态数字绘制。`[markers] beacons = true` 默认开启；放置和删除随游戏同步，其余标记保留原编号。
- 新增可选全开底图 `[map] full_map = true`，覆盖地表、地下和 DLC，默认关闭。仅改变小地图显示，保留存档和赐福、地标的发现状态。

#### 变更

- 地图瓦片、图标图集和 GFX 布局改由游戏文件加载层读取，使用 Overlay 自有纹理绘制。运行和分发均不再依赖外部 `data/map` 文件。
- 地表、地下、DLC 和圆桌厅改用原生地图坐标、图标别名和资源布局。
- 小地图快捷键改用核心统一的 Virtual-Key 输入处理，支持修饰键组合和共享按键事件。
- 原生资源适配覆盖已核对的 1.02～1.17 历史 EXE 和 Steam 1.17.1，按哈希选择菜单、地图、赐福和参数布局；DLC 前不要求 M10 或 DLC 图集。
- 图集名称和数量改为按 GFX/TextureAtlas 引用动态发现，支持超过三个图集的 mod。单个缺失或损坏图集不会阻塞其他有效图集。

#### 修复

- 圆形小地图边框及抗锯齿边缘改为在地图范围内绘制，修复上下左右边缘被裁切的问题；移除 ImGui 窗口边框带来的额外裁剪缩进。
- 修正地图碎片进度同步和瓦片变体选择，获得碎片后显示已探索底图，避免误用未展开图层。
- 为半透明地下地图补齐地表底层。
- 修复将地下状态的填充字节一起读取，导致地表死亡标记被隐藏的问题。
- 修正图标旋转中心、状态图层组合和圆桌厅素材选择。

#### 测试

- 2026-10-02 已由用户确认，在最新版 ELDEN RING 中测试正常。
- 历史版本适配通过 28 个旧目录和最新 EXE 的离线核对，以及三类布局、有界短参数行、死亡/编号/全开选图回归。逐旧版本游戏实测待完成。
- 12 图集通过正式文件回调提取、117 个可见图标的纹理/UV 绘制、失败隔离和重建回收验证。
- 12 张 BC1 图集通过正式 D3D12 上传和逐张 GPU 回读比对，全部 SRV 回收通过。

### [1.1.3] - 2026-06-30

#### 修复
- D3D12 设备恢复与渲染器重置期间，小地图 GPU 资源（纹理、图集精灵、离屏目标）现在会被正确销毁并重建。新增 `Atlas::unloadTextures()` 与 `Renderer` 析构函数清理资源，`prepareTile()` 增加贴图索引边界检查，避免贴图列表重置时崩溃。
- 若初始化时尚未解析游戏内存地址（`csMenuManImp`、`fieldArea`），现在会在 `update()` 中重新查询，使小地图在特征码扫描早于游戏代码加载完成时仍能正常工作。
- 插件 `render()` 入口新增空渲染器保护。

### [1.1.2] - 2026-03-27

#### 修复
- 修复圆形（`circle`）和圆角矩形（`rounded`）小地图模式下，部分装饰物（赐福图标、地标等）渲染到显示范围外的问题。离屏合成现在对所有非矩形模式均应用正确的形状蒙版裁剪。
- 修复靠近形状边缘的装饰物因中心点检查过严而完全不显示的问题。离屏合成已接管裁剪，移除了多余的形状内判定约束。

### [1.1.1] - 2026-03-26

#### 新增
- 新增渲染元素的逐状态额外缩放倍率配置：`extra_tile_scale`、`extra_decoration_scale`、`extra_player_scale` 和 `extra_bearing_scale`。每项支持按缩放状态逗号分隔设置（通过 `scale_key` 切换），与 `scale`/`alpha`/`width_ratio` 用法一致。

#### 变更
- 增大方位指南针指示器的尺寸比例（从 0.25 调整至 0.4），提升可见度。

### [1.1.0] - 2026-03-23

#### 新增
- 旋转模式：设置 `rotate=1` 可使小地图随摄像头朝向旋转，摄像头方向始终朝上。启用时形状强制为圆形。支持按缩放状态分别配置（逗号分隔）。
- 旋转模式下，小地图右上角会显示方位指南针。
- 现在从游戏内存读取摄像机偏航角，实现精确的地图旋转。
- 小地图上现在会显示地标标记，支持方向性图标的旋转。
- 新增 `landmarks_key` 配置项，用于设置切换地标标记显隐的按键（默认：`N`）。
- 新增 `landmarks` 配置项，设置地标标记是否默认显示（默认：`1`）。

#### 修复
- 修复半透明小地图元素（标记、贴图）因双重 alpha 混合导致颜色偏淡的问题。
- 修复配置列表长度不一致时切换小地图预设导致崩溃的问题。
- 修复小地图边缘可能出现亚像素抖动的像素对齐问题。
- 若干内部代码修正与优化。

### [1.0.0] - 2026-03-21

#### 新增
- 可配置小地图形状：`rect`（矩形，默认）、`rounded`（圆角矩形）或 `circle`（圆形），通过 `minimap.ini` 中的 `shape=` 按缩放状态分别设置。
- 可配置 `rounded` 形状的圆角半径：支持百分比（如 `20%`，相对于较短边的一半）或绝对像素值（如 `30`）。
- 可配置形状边框：`border_color`（R,G,B,A，各 0–255）和 `border_width_x10`（宽度 × 10，如 `15` = 1.5 像素）。设置 `border_width_x10=0` 可禁用边框。
- 圆形模式下，小地图自动约束为正方形（取宽高中的较小值）。
- 非矩形模式下，篝火/赐福图标及圆桌厅堂标记现在会被裁剪至小地图形状边界内。

#### 修复
- 修复形状渲染（`rounded`/`circle`）中因 `ShadeVertsLinearUV` UV 钳制不当导致的贴图拉伸问题。
- 修复 `csMenuManImp_` 地址为零时的空指针解引用。
- 移除数据加载中遗留的调试 CSV 输出。
