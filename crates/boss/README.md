# Boss overlay

独立 Rust/egui 动态插件，安装位置为 `overlays/Boss.dll`。Boss 的定义是游戏界面下方显示具名大生命条；目录从运行中的 Param 和 EMEVD 事件生成，名称来自当前游戏语言的 FMG，不分发旧多语言名单。

默认按 `=` 切换紧凑状态与完整列表。完整列表支持地区折叠、搜索、未完成筛选、窗口拖动和调整大小。完整列表打开时，键盘和鼠标交给界面，按 `=` 或窗口关闭按钮返回紧凑状态；未打开复活确认窗口时也可按 `Esc` 返回。加载、Logo、全屏地图、失焦和停止会释放输入捕获。Minimap 仍在游戏 UI 下层，Boss 在上层。

搜索和模板输入支持直接键入文本。本期未接入系统剪贴板，不支持通过 `Ctrl+C/X/V` 与系统剪贴板交换内容。地区和「参考地点」来自 Param 的同地图近邻归类，高度和路线可能不同，不能作为准确导航信息。

`configs/boss.ini` 设置快捷键、默认布局、状态模板、挑战模式和复活开关。在界面修改的设置仅在变化后保存到 `configs/boss-ui.json`，删除该文件可恢复使用 INI。窗口位置和临时筛选只在当前运行保留。文本模板支持 `{kills}`、`{total}`、`{deaths}`、`{igt}`、`{pb}`、`{tries}` 和 `$n`。游戏时间从更新快照读取。

挑战模式保留 `Challenge.txt` 中的 PB、失败次数和起始死亡数。旗标 101 不可用时，普通进度继续显示，挑战记录等待有效条件。超出死亡上限后不再增加 PB；离开漂流墓地后重新建立起始死亡数。切换存档后，应在挑战界面点击「开始本轮」设置当前死亡基线；当前数据服务没有可靠的持久存档身份，不能自动区分跨存档死亡数与本轮死亡增量。PB 和累计失败次数保持不变。外部修改的 `Challenge.txt` 每秒检查一次。

启用复活后，点击已完成战斗前的 `[+]`，核对确认窗口后执行。配方位于 `configs/boss-revival.json`；数字条目表示清零，`{"flag_id": ID, "value": true}` 表示置真。核心在首次写入前验证主旗标、全部辅助旗标和当前上下文，再按配置顺序写入辅助旗标，最后清除主完成旗标。任一目标或上下文不可用时拒绝执行。整组写入不会暂停游戏事件解释器，也不保证回退全部任务和奖励。复活后需要传送或重新加载区域；任务关联或共享场地配方可能改变任务状态。未配置配方的新战斗默认禁用复活，空数组 `[]` 表示明确只清主旗标。配方在插件启动时读取，「重新读取游戏数据」不重载复活配置。

运行中更换 Mod 的 Param 表地址会重新生成目录。需要重新读取同地址的参数或覆盖文本时，在完整列表点击「重新读取游戏数据」。普通传送、全屏地图和暂时不可读的游戏状态不会重复读取整个目录。未知名称显示 `NpcName#ID`；无法证明完成条件的生命条用 `[?]` 表示，不计入完成比例、不允许复活。

这组离线资产生成 211 个战斗，覆盖旧名单的 207 项，并增加后期 Patches、Adula 前期战斗、Lansseax 前期战斗和格密尔火山第一场 Fallingstar Beast。目录按生命条战斗计数，投降或撤退也可能形成完成状态；外部复活配置未为这 4 场提供配方。

旧字段、真实数据来源、覆盖和限制见 [数据来源](../../docs/boss-data-sources.md) 和 [事件与战斗契约](../../docs/boss-events.md)。离线生产数据、DLL 和 WARP 检查不能替代游戏内画面、输入和性能验收。
