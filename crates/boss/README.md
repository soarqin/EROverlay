# Boss overlay

独立 Rust/egui 动态插件，安装位置为 `overlays/Boss.dll`。Boss 的定义是游戏界面下方显示具名大生命条；目录从运行中的 Param 和 EMEVD 事件生成，名称来自当前游戏语言的 FMG，不分发旧多语言名单。

当前采用用户批准的旧版 207 项计数范围，Hinterland 两场独立保留。`configs/boss-encounters.json` 只保存三组无法由 Param 表达的跨场关系，不保存 Boss 名称、地区、位置或完整名单：

| 关系 | 主场／主完成旗标 | 关联场次 | 进度规则 |
|---|---:|---:|---|
| Adula | 后场 `1034420800` | 早场 `1034500800` | `primary`：只认后场完成 |
| Lansseax | 后场 `1041520800` | 早场 `1037510800` | `any`：后场或早场击杀任一完成；撤退 `1037510810` 不算击杀 |
| Patches | 初战 `31000800` | 后战 `31000850` | `primary`：初战含投降完成；后战不单独计数 |

关系配置在插件初始化时读取。「重新读取」不重载关系配置或复活配方。配置缺失或无效时记录错误并禁用跨场关系，不使用内置关系表；Mod 缺少主场完成事件时，关联场次保留自己的事件旗标。范围依据和降级规则见 [207 项范围说明](../../docs/boss-207-scope-2026-11-02.md)。

默认按 `=` 切换紧凑状态与完整列表。完整列表支持地区折叠、搜索、未完成筛选、窗口拖动和调整大小。完整列表打开时，键盘和鼠标交给界面，按 `=` 或窗口关闭按钮返回紧凑状态；未打开复活确认窗口时也可按 `Esc` 返回。加载、Logo、全屏地图、失焦和停止会释放输入捕获。Minimap 仍在游戏 UI 下层，Boss 在上层。

搜索和模板输入支持直接键入文本。本期未接入系统剪贴板，不支持通过 `Ctrl+C/X/V` 与系统剪贴板交换内容。地区采用旧 C++ 的 32 个大区粒度，标题读取当前游戏语言的 PlaceName。目录归属优先使用地区／地图和 Param 关联，缺失时才用有界近邻；「参考地点」仍可能与高度和路线不符，不能作为准确导航信息。实际归档保留 207 场；玛丽戈按游戏 Param 归入青蓝海岸，与旧名单的卡罗隐藏墓地有一项差异，见 [地区来源和验证](../../docs/boss-layout-regions-2026-11-03.md)。

有效玩家大区变化时，仅展开当前区并收起其他区；同区手动展开／收起会保留。加载中或未知地区不重置。搜索、只看未完成和地区筛选期间暂缓自动折叠，清除全部筛选后应用最新有效区一次。搜索继续尊重手动折叠，可点击匹配组标题展开；计数仍显示全组进度。重新读取资源后初始化新目录一次，普通进度更新不覆盖折叠状态。

`configs/boss.ini` 设置快捷键、默认布局、状态模板、挑战模式和复活开关。在界面修改的设置仅在变化后保存到 `configs/boss-ui.json`，删除该文件可恢复使用 INI。窗口位置和临时筛选只在当前运行保留。文本模板支持 `{kills}`、`{total}`、`{deaths}`、`{igt}`、`{pb}`、`{tries}` 和 `$n`。游戏时间从更新快照读取。

挑战模式保留 `Challenge.txt` 中的 PB、失败次数和起始死亡数。旗标 101 不可用时，普通进度继续显示，挑战记录等待有效条件。超出死亡上限后不再增加 PB；离开漂流墓地后重新建立起始死亡数。切换存档后，应在挑战界面点击「开始本轮」设置当前死亡基线；当前数据服务没有可靠的持久存档身份，不能自动区分跨存档死亡数与本轮死亡增量。PB 和累计失败次数保持不变。有有效存档时，外部修改的 `Challenge.txt` 每秒检查一次；菜单或无效存档不会推进挑战记录或保存挑战结果。

状态列用空心圆表示未击杀、轻量勾表示已击杀、带点菱形表示未知；三态名称起点相同。地区标题整行可点击，进度靠右，当前游戏地区用细强调线标记；展开内容适度缩进。名称和窄列标题截断后仍可悬停查看全文。状态与折叠控件支持键盘焦点，焦点有可见提示。

启用复活后，点击已完成战斗前的勾，或聚焦后按 Space／Enter，核对确认窗口后执行。可复活的标记悬停时显示轻量背景和操作提示；未击杀、未知或当前不允许复活时不会激活确认。配方位于 `configs/boss-revival.json`；数字条目表示清零，`{"flag_id": ID, "value": true}` 表示置真。提交时重新读取当前上下文和完成旗标；核心在首次写入前验证当前为真的完成见证、全部写入地址和确认窗口的上下文，再清除见证旗标。任一目标或上下文不可用时拒绝执行。

普通配方按原顺序写入辅助旗标，最后清除主完成旗标。Lansseax 仅早场击杀时，以当前为真的早场旗标作为最后清除的见证，将后场主旗标移入本次辅助清零操作；完整目标和值集合与原配方相同，不添加推测写入。Patches 后战旗标既不阻止初战配方复活，也不由初战配方清除。整组写入不会暂停游戏事件解释器，也不保证回退全部任务和奖励。复活后需要传送或重新加载区域；任务关联或共享场地配方可能改变任务状态。未配置配方的新战斗默认禁用复活，空数组 `[]` 表示明确只清主旗标。

目录在七张 Param 表地址（新增 PlayRegionParam）和当前语言可用后开始准备，不再等待进入存档。语言尚未就绪时每 500 ms 检查一次；VFS 暂未接收的任务保留退避与期限。目录准备不查询存档状态或读取旗标。存档状态回调不可用或 `valid=0` 时，插件不批读进度旗标、不执行复活，也不保存挑战结果。进入有效存档后，只更新进度、死亡数、时间、玩家地区和必要的条件地名快照。

条件地名的候选文本及显示／隐藏旗标在初始化时缓存；菜单只选明确无条件的文本，否则显示地图标识。有效存档出现后只批读这份小型条件计划，旗标变化时更新地名和搜索快照，不重读 Param、事件、FMG 或场景。当前归档的 207 行没有需要查询条件旗标的候选地名，标签内容不变。Mod 的未知条件不会被当作假值。

运行中更换 Mod 的完整非零 Param 表地址组会取消旧任务并重新生成目录。需要重新读取同地址的参数或覆盖文本时，在完整列表点击「重新读取」。普通进档、传送、全屏地图、临时零地址和暂时不可读的游戏状态不会重复读取整个目录；真正的 Param 地址换代仍需重新准备。未知名称显示 `NpcName#ID`；无法证明完成条件的生命条用带点菱形表示，不计入完成比例、不允许复活。

Boss 最多持有 16 个活动文件 token，核心共享请求池上限仍为 128。事件、文本和场景的实际文件名带 `.dcx`。每次更新共用约 2 ms 软预算，最多提交 32 项、完成或终止 32 项、展开 32 张地图。新发现的必需链接先于宽泛地图探测尝试，使原有重试等待与其他读取重叠；已排队的可选任务升格不改变顺序。普通可选缺失只探测一次，必需传输失败仍最多延后重试一次，格式无效的数据不重读。单任务 10 秒、本次资源等待 60 秒期限后分批结束等待并保留明确错误，可用「重新读取」重试。原生回调仍需安全退休；单次宿主调用或解析不能被预算中断，这些期限不保证游戏 I/O 或帧耗时。

本轮真实归档的受控虚拟 60 Hz 调度从 356–357 次更新降至 93–94 次，折合约 5.94 秒降至 1.55–1.57 秒；这不是游戏 VFS 或 FPS 测量。菜单预加载、条件地名、调度、失效策略和复现入口见 [菜单预加载与层级修复](../../docs/boss-menu-layer-fix-2026-11-02.md)。此前 4 token 的结果与 DLL 回执保留在 [首次读取修复](../../docs/boss-loading-fix-2026-11-02.md)，不代表当前调度参数。

原始离线事件发现曾生成 211 条静态候选，包含三组跨场记录和一个引用缺失实体 `1038540800` 的残留模板；不能把它称为第一场陨星兽或已确认的战斗。当前选定范围在三组关系之外，对缺少精确 Param 关联的候选读取场景实体索引。3 张真实 MSB 共 4,530,744 B，通用负证据筛除残留模板的 2 条显示指令，使生产计划的 347 条具名生命条指令保留 345 条。范围收敛时得到 207 项目录、95 个细分组；本轮地区修复将分组归并为 32 个大区。旧 207 项仍全部一对一对应，具名成员完整，未缺少归档显示指令；当前证据见 [地区来源和验证](../../docs/boss-layout-regions-2026-11-03.md)，历史范围审计位于 `target/boss-207-delivery-audit`。

场景路径遵循已核实的原生地图区域选择规则：本轮 `m31`、`m60` 地图只读 `mapstudio:/`；`m61` 属于可能使用 `mapstudio_dlc2:/` 的区域，因尚未读取原生全局开关而保守请求两个别名。任一索引找到角色都保留候选；仍未找到角色但待查路径存在未知读取、解析或预算失败时，也不排除候选。未知指令、代理对象和无法证明局部实体缺失的情况同样保留。离线审计使用显式解压后的 MSB，不证明原生 VFS 别名的在线可用性或 Mod 覆盖结果。缺少场景证据时可能保留更多候选，不强行维持 207 项。

旧字段、真实数据来源、覆盖和限制见 [数据来源](../../docs/boss-data-sources.md)、[事件与战斗契约](../../docs/boss-events.md) 和 [207 项范围说明](../../docs/boss-207-scope-2026-11-02.md)。离线生产数据、DLL 和 WARP 检查不能替代游戏内画面、输入、复活和性能验收。
