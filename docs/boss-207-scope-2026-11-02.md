## 场景残留与未知保留

`1038540800` 不是可确认的“第一场格密尔火山陨星兽”：该原版 MSB 无对应角色／模型，但 EMEVD 留有公共生命条和结算模板。生产代码没有写死其旗标，也不把 207 或旧名单作为排除规则。

先使用已核对的精确 Param 完成旗标、显示实体或同地图行 ID 定位关系；无法定位的候选才异步读取 MSB。此归档只需 `m31_00_00_00`、`m60_38_54_00`、`m61_49_44_00` 三图，原始解压数据合计 4,530,744 字节。纯 Rust MSBE 读取器与本机 SoulsFormats 对五张真实场景的 Actor 字段、实体和 group ID 独立差分通过。场景不用于取代具名生命条定义。

原生 EXE 的 UTF-16 格式字符串证明 `mapstudio:/%s.msb` 与 `mapstudio_dlc2:/%s.msb`；继续核对实际选择函数，确认只有地图 area 位于 `{20,21,22,25,28,40,41,42,43,61}` 且引擎全局开关为真才使用 DLC2，其余永远使用 base。生产纯函数复现这份地图路由 bitset；本轮 m31／m60 只请求 base。DLC2 候选地图的引擎开关未读取，因此 m61 保守检查两条 alias；任一含角色即保留。不会把不适用的 DLC 路径失败计入 base 场景的负证据。

[原生路径证据](evidence/boss-207-scope-2026-11-02/native-scene-mounts.json) 保存当前 EXE 哈希、真实 RIP 引用、函数边界、机器码与完整反汇编。它还核对地图字符串构造；本期 MSB 只读取资源版本 `_00`，不推断特殊地图版本的文件名。

缺失角色只有在所有适用路径读取成功且语义检查通过时才作为负证据：要求简单本地公共模板、无已知跨图同实体血条、无 proxy／region 冲突、无未知目标操作、零变体等。DummyEnemy 和实体 group 都算角色正证据；未知事件操作保持候选。MSB 每个文件 64MiB、累计场景解析 32MiB，请求数与事件展开也有上限。超限、失败、缺失及无法解析均保留未知并提示资源不完整，不把 ABI 的泛化 `FILE_FAILED` 当作已证实不存在。相同范围已有 Param 定位的其他生命条也保护整组。

本次显式归档输入不推断现场 VFS 成功或 Mod 覆盖优先级。实际 VFS 如无法读取残留模板所属的 base 场景，会保留候选，可能显示 208 条及资源提示；不能为强制 207 而吞掉未知。去掉所有场景输入的负向回归确实得到 208，而非硬凑 207。当前只扫描三个需要后备证据的场景，不能证明所有 Mod 都没有无生命条的跨图 Actor；跨图动态实体、不同 MSB 版本或新增事件形状仍需补充证据。场景与事件关联仅在初始化／数据重载执行，渲染线程不读文件、不解析场景、不做新目录扫描。

## 重现与升级

普通根目录 fmt／check／clippy／test／Release 不依赖游戏或旧 C++。完整逐项归档审计需显式提供解压文件：

```powershell
python tools/audit_boss_catalog.py --reference target/cpp-reference --params target/research --events E:/path/to/EMEVD --scope selected --scenes E:/path/to/MSB --output target/boss-207-audit
```

Param／文本输入同 [事件契约](boss-events.md)。MSB 路径只用于可选审计及 DLL probe，不是产品磁盘读取路径。真实 DLL 探针可运行：

```powershell
./target/release/boss_probe.exe ./package/overlays/Boss.dll E:/path/to/params-and-bnds E:/path/to/EMEVD target/boss-probe E:/path/to/MSB
./target/release/eroverlay-harness.exe ./package 3
```

安装包包含真实三个 Release DLL、精简配置、准确 `source.json` 和逐文件 SHA-256 manifest，不含游戏资产或旧多语言目录。完全退出游戏后更新核心 `EROverlay.dll`、旧 `overlays/Minimap.dll` 及 `overlays/Boss.dll`，加入 `configs/boss-encounters.json`。首次安装 Boss 才需加入 Boss INI 与复活 JSON；已有 Rust 配置、`boss-ui.json` 和 `Challenge.txt` 保留。默认 `=` 展开／收起，`Esc` 关闭普通完整窗口；复活确认时先确认或取消。没有自动安装、注入、启动游戏或推送。
